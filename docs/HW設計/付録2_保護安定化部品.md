# 付録: 保護・安定化用部品

本付録では、車載カーナビシステムの電源ラインや信号ラインに使用する保護・安定化用部品を整理する。

## 1. 部品一覧

| 部品 | 主な役割 | 想定配置 | 備考 |
| --- | --- | --- | --- |
| ヒューズ | 短絡・過電流時に回路を遮断する | 車載バッテリー直後、DC/DC入力前 | 配線保護を目的に、バッテリーに近い位置へ配置する |
| ポリヒューズ | 過電流時に抵抗値を上げ、復帰可能な保護を行う | Pico用5V分岐、または小電流の補助電源ライン | 復帰型だが、発熱と電圧降下に注意する |
| TVSダイオード | 瞬間的なサージ電圧を吸収する | 12V入力ライン、5V出力ライン、ACC入力ライン | 車載環境のロードダンプやスパイク対策として検討する |
| 逆接保護ダイオード | 電源の逆接続から回路を保護する | 12V入力ライン | 電圧降下が発生するため、電流容量と発熱に注意する |
| 逆接保護MOSFET | 低損失で逆接続から回路を保護する | 12V入力ライン | ダイオード方式より電圧降下を抑えやすい |
| LCフィルタ | 電源ラインのノイズを低減する | DC/DC入力側、DC/DC出力側 | コイルとコンデンサで構成する。発振や突入電流に注意する |
| フェライトビーズ | 高周波ノイズを抑制する | 5Vライン、信号ライン | 大電流ラインでは定格電流を確認する |
| 電解コンデンサ | 電源の低周波変動や瞬間的な負荷変動を吸収する | Pi 5 PD電源拡張ボード入力前、Pico用5V分岐、オーディオ電源ライン | 容量、耐圧、温度定格、ESRを確認する |
| セラミックコンデンサ | 高周波ノイズをGNDへ逃がす | ICやモジュールの電源ピン近傍 | 0.1uF程度を近接配置することが多い |
| 低ESRコンデンサ | 急な負荷変動に対する電源安定性を高める | Pi 5 PD電源拡張ボード入力前、USB周辺機器の電源ライン | リップル電流、温度定格を確認する |
| 電源スイッチIC | 過電流保護、過熱保護、ソフトスタートなどを行う | 5V電源ライン | Pi 5を直接給電する設計では必須ではないが、保護強化に有効 |
| 電圧監視IC | 電圧低下や異常電圧を検知する | 5Vライン、Pico入力 | 低電圧時の誤動作検出やログ記録に利用できる |
| 分圧抵抗 | 高い電圧をGPIOで読める電圧へ変換する | ACC入力ライン | Pico GPIOへ入れる場合は3.3V以下にする |
| 電流制限抵抗 | 入力信号ラインの過電流を抑える | ACC入力ライン、GPIO信号ライン | 保護ダイオードやTVSと組み合わせる |
| フォトカプラ | 電気的に絶縁して信号を伝達する | ACC入力ライン | ノイズやGND差が気になる場合に有効 |
| フォトMOSリレー | GPIO信号で小信号接点を絶縁してON/OFFする | Pi 5 J2電源ボタン端子の短時間短絡、ドアロック操作信号 | 機械接点がなく、Picoから電源ボタン押下を模擬しやすい |
| リードリレー | 小信号接点を機械接点でON/OFFする | Pi 5 J2電源ボタン端子の短時間短絡 | コイル駆動回路とフライバックダイオードが必要 |
| RCフィルタ | 入力信号のチャタリングやノイズを抑える | ACC入力ライン | ACC ON/OFF判定の安定化に使う |

## 4. Pi 5前段の推奨構成

Raspberry Pi 5へPD電源拡張ボードから給電する場合、車載12Vをそのままボードへ入れず、12V入力側に保護・安定化を入れる。

```text
車載バッテリー 12V
  ↓
入力ヒューズ
  ↓
逆接続保護（MOSFET推奨、試作はショットキー可）
  ↓
12V用TVSダイオード
  ↓
フェライト / DCノイズフィルタ
  ↓
入力電解コンデンサ + 入力セラミックコンデンサ
  ↓
Pi 5 PD電源拡張ボード
  ├─ USB-C / PD出力 → Raspberry Pi 5
  └─ 5V VBUS → Pico用ポリヒューズ → Raspberry Pi Pico
```

## 5. ACC入力の推奨構成

ACC 12VをPicoのGPIOで読む場合、直接入力せず、入力保護回路を通して3.3V信号へ変換する。

```text
ACC 12V
  ↓
ヒューズ / 逆接続保護 / 12V側TVS
  ↓
入力コンデンサ
  ↓
降圧コンバーター 3.3V出力
  ↓
電流制限抵抗
  ↓
3.3V TVS または ツェナーダイオード
  ↓
RCフィルタ / プルダウン
  ↓
Pico GPIO
```

降圧コンバーターはACC ON/OFF判定用の信号源として使用し、Pico本体の常時待機電源には使用しない。絶縁が必要な場合は、降圧コンバーター方式の代わりにフォトカプラやデジタルアイソレータを検討する。
