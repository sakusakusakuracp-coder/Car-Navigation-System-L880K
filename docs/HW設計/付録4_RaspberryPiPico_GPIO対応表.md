# 付録4: Raspberry Pi Pico GPIO対応表

本付録では、Raspberry Pi PicoのGPIO端子を一覧化する。物理ピン番号は標準的なRaspberry Pi Picoの40ピンDIP配置を前提とする。Pico互換品やPico Wなどを使用する場合は、基板ごとのピン配置、オンボードLED、無線機能との内部接続を必ず確認する。

主設計書の電源管理に関係する割り当ては、[4.1.4.4 Raspberry Pi Pico GPIO対応表(電源関係)](ハードウェア設計書.md#sec-4144)に抜粋して記載する。

設計上の注意点は以下とする。

- Pico GPIOへ入力する信号は3.3V系に限定し、車体12V信号を直接接続しない。
- 未使用GPIOは原則として未接続とし、必要に応じてソフトウェア側で入力またはプル設定を行う。
- Pi 5 J2電源ボタン端子の操作にはPico GPIOを直接接続せず、フォトMOSリレーまたは小信号リレーの接点を使う。
- ADC兼用GPIOを使う場合も、入力電圧は0V-3.3V範囲に収める。
