# 付録3 カーナビUI実装状況

更新日: 2026-09-28

本付録では、ソースコードの実装と実車での検証を区別する。画面が表示できるだけでは、機器との接続・動作を確認したことにはしない。

## 1. 画面と操作

| 画面・機能 | 現在の実装 | 残る確認・制約 |
| --- | --- | --- |

| カメラ | 前後左右の実JPEG表示、方向切替、期限切れ画像の消去、方向別録画状態、容量・送信状態 | CSI実機・サブコン・バックギア入力・4方向同時性能 |

| 警告 | 重要度、確認、原因回復、再発を区別した最大100件の一覧とJSON保存 | 過去の発生中警告は未再確認と表示。破損ファイルを上書きしない |

## 2. 共通動作

- 上部バーは通常時に時計・サービス・OBD2・GPS・録画状態を表示する。未確認警告があるときは同じ領域を警告表示に切り替える。中央の操作部品には重ねない。
- 下部の画面切替は維持し、ナビ用外部ウィンドウの表示領域を警告の発生で移動させない。
- 設定保存と外部通信は画面用スレッドの外で実行する。同種操作の連打、保存と復元、録画設定の読込と適用の競合を抑える。
- 適用済み値は処理成功後に更新する。通信切断時は結果不明の可能性を表示し、操作を自動再送しない。
- GPS・OBD2・録画・送信には各サービスの通知期限を適用する。冷却・音楽は5秒の更新停止を監視する。
- 未取得の車両情報を0や正常値で補完しない。取得できない冷却ファン回転数も推測しない。
- 録画再生中に画面を離れると停止する。準備中に画面を離れた場合も、遅れて届いた結果を再生に使わない。
- 録画再生は車速失効・走行開始でも停止する。設定等の受付済み操作の取消は行わない。

## 3. 主な実装ファイル

| ファイル | 役割 |
| --- | --- |
| `main_app.py` | UIと追加機能の組立・起動・終了 |
| `ui/controllers/screen_controller.py` | 画面選択、ナビ表示、後方表示優先 |
| `ui/controllers/service_bridge.py` | ナビ・OBD2・現在地・カメラ・送信・冷却とのIPC |
| `ui/controllers/feature_controller.py` | 設定、音楽、録画一覧、警告の非同期操作とQML公開 |
| `ui/controllers/mopidy_client.py` | Mopidy JSON-RPC要求・応答検証 |
| `ui/controllers/official_music.py` | 公式URLの専用ブラウザ起動・Sway配置・退避・所有プロセスの終了 |
| `ui/controllers/audio_output.py` | `pactl`による指定USB出力の存在監視。出力設定は変更しない |
| `ui/controllers/recording_library.py` | 共通台帳の読込と再生用コピー |
| `ui/config/preferences.py` | 利用者設定の検証・原子的保存・復元 |
| `ui/config/file_lock.py` | UI二重起動と設定保存のOSロック |
| `ui/state/warnings.py` | 警告の確認と回復を分離した履歴 |
| `ui/state/app_state.py`ほか | サービスから取得した表示状態と期限 |
| `ui/qml/` | 各画面、警告一覧、録画再生、明暗テーマ |

パスは`src/raspberry_pi5/`からの相対パス。設定先と導入方法は[付録9 UI追加機能導入手順](付録9_UI追加機能導入手順.md)を参照する。

| 冷却・サブコントローラ1/2・ドアロック | 内部実装あり。実配線・波形・入出力の安全性は別途確認。ドアロックをUI操作に開放していない |

| 音声の自動音量低減・DAC抜差し制御 | 未実装。DACの存在監視は実装したが、経路・ミュート・誤迂回防止は未実装 |
| LIVI | ネイティブプロセス起動・Sway配置・JSON Lines IPCは内部実装あり。電話接続状態と音声イベントの正式API連携、実機Android Auto接続は未検証 |
| サラウンド合成、BLE TPMS | 未実装またはT.B.D |
| Wi-Fi/Bluetooth設定、画面輝度、OS再起動 | 未実装。操作可能に見える仮ボタンは表示しない |

## 5. 検証

自動試験では、設定保存失敗時の旧設定保持、警告の確認・回復・再発、Mopidyの模擬HTTP通信、録画設定の保存と停止、再生用コピー、Qtでの動画復号、画面離脱時の結果破棄を確認する。QMLは800×480と1280×720で描画し、明暗テーマも確認する。

これらはLinux実機のSway重なり順、音声出力、CSI、GPIO、Googleアカウントを用いた結合試験の代わりにはならない。
