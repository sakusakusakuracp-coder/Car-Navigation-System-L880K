# 付録: アプリ機能一覧

本付録では、ハードウェア設計の前提となるアプリケーション機能を整理する。

## 1. 機能一覧

| 機能 | 概要 | 関連ハードウェア |
| --- | --- | --- |
| 現在地表示 | GPS情報を取得し、現在地を地図上に表示する | GPSモジュール、Raspberry Pi 5、ディスプレイ |
| 目的地設定・ルート検索 | 目的地を設定し、現在地からのルートを探索する | Raspberry Pi 5、タッチパネルディスプレイ |
| 音声案内 | ルート案内や警告を音声で出力する | USB DAC、オーディオアンプ、スピーカー |
| 地図表示 | オンラインまたはオフライン地図を表示する | Raspberry Pi 5、ディスプレイ、ストレージ |
| ドライブレコーダー | 前方・後方カメラの映像を記録する | 前方カメラ、後方カメラ、SSD |
| オーディオ再生 | USB DAC経由でカーアンプへ音声を出力する | USB DAC、オーディオアンプ |
| Bluetooth音源再生 | スマートフォンとBluetooth接続し、音楽を再生する | Bluetoothモジュール、USB DAC、オーディオアンプ |

## 2. 本体設計書との関係

本体のハードウェア設計書では、上記機能のうちハードウェア構成や電源・配線・入出力設計に影響する内容のみを本文に記載する。アプリケーションの詳細仕様、画面仕様、操作仕様は別途ソフトウェア設計書で定義する。
